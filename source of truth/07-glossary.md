# Glossary

| Term | Meaning |
|---|---|
| Agency operator | Vendor team deploying and supporting the platform |
| Approval workflow | Submission and authorized review of a proposed change |
| Audit event | Actor, action, timestamp and affected record |
| Banglish | Bangla written in Latin characters or mixed Bangla-English |
| Branch | Hospital campus/location |
| Clinical advice | Diagnosis, treatment, medication or symptom-triage guidance; excluded |
| Dedicated installation | Separate environment, database and credentials for one hospital |
| Effective date | Date/time from which a fee, schedule or record is valid |
| HIMS | Hospital Information Management System |
| Knowledge base | Approved hospital information searchable by the assistant |
| MVP | Minimum viable product: smallest dependable release to sell and validate |
| RBAC | Role-based access control |
| RPO | Recovery Point Objective: maximum acceptable data loss measured in time |
| RTO | Recovery Time Objective: target restoration time |
| Schedule exception | One-off closure/cancellation/change overriding a recurring schedule |
| SaaS | Software as a Service |
| Slot capacity | Number of appointments allowed in a time slot |
| Source grounding | Restricting AI answers to retrieved approved information |
| Abstention | AI declines to answer because reliable information is unavailable |
| UAT | User Acceptance Testing by customer representatives |
